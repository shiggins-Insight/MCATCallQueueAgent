# MCAT Call Queue Agent

Beta design for shared-mailbox research and response drafting, with human
architect review in one persistent Teams group chat.

- [Design and deployment guide](docs/DESIGN_GUIDE.md): requirements, decisions,
  reported results, open questions, and the next setup step.
- [Connectivity test card](preflight/connectivity_card.json): paste-ready JSON
  for the manual Power Automate feedback test.

These files are documentation and a test-card payload, not an importable Power
Automate solution. No production deployment is recorded.
